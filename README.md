# 🐍 PyPrep Coach

An interactive **Python interview trainer** you run on your own machine. It asks
you Python questions, you write code in an editor, click **Validate**, and an AI
tutor (a **free** LLM — Google Gemini by default) tells you whether you're right,
how to improve, and what to study next — all while you earn XP, build a streak,
and (optionally) run your code for real against test cases.

![two-pane layout: question on the left, editor on the right, feedback below]

---

## ✨ Features

- **Two-pane workspace** — question on the left, code editor on the right, AI feedback below.
- **AI tutor** — questions are generated by a free LLM and answers are graded by it, with a friendly senior-engineer voice. Works with **Google Gemini (free), Groq, OpenRouter free models, or a local Ollama** — no paid API required.
- **Real execution (optional)** — your code is run against hidden test cases in the browser via [Pyodide](https://pyodide.org), so the verdict is backed by actual results, not just opinion.
- **14 topic areas** — basics, strings, lists/dicts/sets, comprehensions, functions & closures, OOP, decorators, generators, exceptions, file I/O, recursion, sorting/searching, interview patterns, and Python gotchas.
- **Adaptive** — more questions on the topics you miss; difficulty rises as you improve.
- **Mock interview mode** — timed, 5 questions, no hints, with a report card at the end.
- **Gamification** — XP, levels, a daily streak, an accumulating *Topics to brush up* list, and confetti (toggleable).
- **Progress dashboard** — accuracy by topic, questions solved, weak areas, and mock-interview history.
- **Dark mode by default** with a light-mode toggle.
- **Works offline too** — with no API key it falls back to 5 bundled questions and a rule-based tutor.

## 🚀 Quick start

### 1. Install Node.js
You need **Node.js 18 or newer** (20+ recommended). Get it from
<https://nodejs.org>. Verify with:

```bash
node --version
```

### 2. Install dependencies
From the project folder:

```bash
npm install
```

### 3. Add a free AI key
Copy `.env.example` to `.env`:

```bash
# macOS / Linux
cp .env.example .env

# Windows PowerShell
Copy-Item .env.example .env
```

Open `.env` and pick a provider. The default is **Google Gemini**, which has a
generous free tier and needs no credit card:

1. Get a free key at <https://aistudio.google.com/apikey>.
2. Paste it into `.env`:

```
LLM_PROVIDER=gemini
LLM_API_KEY=your-free-api-key-here
```

That's it — Gemini's free tier is the default. Prefer something else? Change
`LLM_PROVIDER` to one of these (all free, all OpenAI-compatible):

| `LLM_PROVIDER` | Get a free key | Default model |
| --- | --- | --- |
| `gemini` *(default)* | <https://aistudio.google.com/apikey> | `gemini-2.0-flash` |
| `groq` | <https://console.groq.com/keys> | `llama-3.3-70b-versatile` |
| `openrouter` | <https://openrouter.ai/keys> | `meta-llama/llama-3.3-70b-instruct:free` |
| `ollama` | none — runs locally | `llama3.2` |

> The key is read **only** by the backend (`server.js`). It is never sent to the
> browser and `.env` is git-ignored. If you skip this step, the app still runs
> using the 5 bundled questions and an offline rule-based tutor.

**Fully local option (no key at all):** install [Ollama](https://ollama.com),
run `ollama pull llama3.2`, then set `LLM_PROVIDER=ollama` in `.env` and leave
`LLM_API_KEY` empty.

### 4. Start the server

```bash
npm start
```

### 5. Open it in Chrome
Go to **<http://localhost:3000>**.

That's it. Pick a topic and difficulty (or hit **🎲 Surprise me**) and start
solving.

## 🧠 How it works

```
Browser (public/)                      Node backend (server.js)            Free LLM
─────────────────                      ────────────────────────            ────────
pick topic/difficulty  ──POST /api/question──▶  generate or pick question ──▶  (Gemini/Groq/
  │                                             │                              OpenRouter/
write code + Validate  ──runs Pyodide locally   │                              Ollama)
  │                                             │
  └──────────────────── POST /api/validate ──▶  grade answer ─────────────▶  (LLM)
                                                 │
                                    saves progress.json
                                                 │
   rendered feedback  ◀───────────────── feedback JSON + XP
```

- **`POST /api/question`** — returns one question. With a provider configured, the
  LLM authors a fresh question matching the requested topic/difficulty and
  avoiding ones you've already seen. Otherwise it serves a bundled seed question.
- **`POST /api/validate`** — the LLM returns **JSON only** with `verdict`,
  `summary`, `improvements` / `what_went_wrong` / `how_to_fix` /
  `corrected_approach`, `concepts_to_review`, `complexity`, and `encouragement`.
  The backend strips code fences and parses it safely, with a friendly fallback
  if the AI is unreachable.
- **`progress.json`** — your XP, streak, per-topic stats, seen questions, and
  brush-up list, stored on disk so it survives browser changes. It is git-ignored.

## ⚙️ Configuration

All optional, in `.env`:

| Variable | Default | Purpose |
| --- | --- | --- |
| `LLM_PROVIDER` | `gemini` | One of `gemini`, `groq`, `openrouter`, `ollama`. |
| `LLM_API_KEY` | _(none)_ | Your free provider key. Not needed for `ollama`. Without it, offline mode is used. |
| `LLM_MODEL` | _(per provider)_ | Override the model, e.g. `gemini-2.5-flash`. |
| `LLM_BASE_URL` | _(per provider)_ | Override the API base URL (self-hosted / custom). |
| `PORT` | `3000` | Port the local server listens on. |

> Any OpenAI-compatible endpoint works: set `LLM_BASE_URL` + `LLM_MODEL` and
> point it at your own server. If a model call fails, the app degrades gracefully
> to the bundled seed questions and the rule-based tutor.

**Bring your own key note:** the browser never sees the key; only the backend
makes outbound calls to your chosen provider.

## 🛠 Troubleshooting

- **Editor looks like a plain text box** — Monaco is loaded from a CDN; without
  internet the app falls back to a textarea. Everything still works.
- **"Execution unavailable"** — Pyodide is also CDN-loaded. Grading falls back to
  the AI/rule-based tutor when it can't run.
- **"Offline tutor" badge on feedback** — the API key is missing or the model
  call failed; check `.env` and your network.
- **Port already in use** — set `PORT=3001` in `.env` and reopen the matching URL.
